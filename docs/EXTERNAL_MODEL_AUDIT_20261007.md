## 结论与动作

1. 当前主要问题不是训练命令，而是手机视角标注量和域差异；重复训练 104 张图片不能解决漏检。
2. 公开混合交通模型原始权重在关键冲突视频上比本地微调版本更适合作为**回放参考候选**，但它在 11 张正式测试图上的 IoU 复核仅匹配 2/26 个电动车框，不能直接宣布为最终模型。
3. 本地微调版本判定为失败候选，保留输出用于追溯，不接入手机、不替换 Android 资产。
4. 正式训练 best.pt、独立测试集、人工标签和候选扫描均保持不变；没有启动自动标注或安全预警。
5. 下一步只有在关键视频补充足够的人工确认连续框后，才重新做本地微调；优先补 `170525` 中央迎面目标以及误报告警对应帧。
