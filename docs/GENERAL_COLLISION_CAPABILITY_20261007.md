# BlindNav 通用碰撞风险能力回放（2026-10-07）

## 能力定义

每个被跟踪目标都经过同一套时序判断，不按某一张图片写死：

1. 取目标框底边中心作为路面接地点；
2. 保留连续轨迹，计算接近速度、面积增长和横向切入；
3. 判断接地点当前或短期预测是否穿过中央行进走廊；
4. 路线外且远离/静止：不报警；
5. 预测即将切入：注意；
6. 连续占用走廊并达到近距离：警告；
7. 刚切入且已经近距离占用，或持续快速接近：危险；
8. 相机/路线证据不足：减速，不输出安全结论。

这套规则适用于两轮车，也适用于已经进入统一风险接口的其他前方障碍物类别。

## 限制

这证明了风险规则能对同一类事件统一处理，不证明检测模型已经达到安全部署标准。下一步必须对 25 段有告警视频逐帧复核，区分真正路线冲突、正常横向通过和停放目标，再冻结阈值。
