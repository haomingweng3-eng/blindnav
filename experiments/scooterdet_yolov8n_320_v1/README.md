# ScooterDet YOLOv8n 320 v1

本目录是公开数据训练实验的可审计产物：

- `dataset_summary.json`：数据总量和类别总数；
- `split_manifest.csv`：每张图片的连续帧组和 split；
- `results.csv` / `results.png`：30 轮训练记录；
- `confusion_matrix.png`：独立 test 混淆矩阵；
- `test_predictions.jpg`：test 预测样例。

完整口径见仓库根目录 `BASELINE_REPORT.md`。原始 ScooterDet 图片和标签受 CC BY 4.0 约束，没有复制到本仓库。
