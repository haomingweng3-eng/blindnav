# 引路与碰撞预警实现记录

当前手机链路已接入统一引路状态机：

- `保持直行`
- `向左绕行`
- `向右绕行`
- `注意`
- `停止`
- `前方情况不明，请减速`

`GeometryWalkableRegionEstimator` 是可行走区域模型的保守回退实现：使用画面下半部、中央路线和目标接地点估计局部自由空间，并根据左右占用选择绕行方向。它不输出绝对距离，也不把单帧框当作碰撞结论。

近距离中央目标在背景运动补偿不可用时会至少升级为“注意”，不会继续显示绿色普通跟踪。只有连续时间证据满足接近和路线冲突条件时才升级为“危险”。

4060 回放和手机端共享 `TemporalRiskEngine` 的风险语义；回放 trace 额外记录 `guidance_state`、`guidance_reason` 和 `guidance_confidence`，用于生成可视化演示和独立统计。

当前可行走区域仍是几何回退，后续可以通过 `WalkableRegionEstimator` 接入轻量分割或自由空间模型，不覆盖历史标签、模型或测试集。
